# C# Fundamentals Lab

A collection of 57 hands-on C# console exercises exploring core language features, object-oriented design, memory management, and concurrency.

## Topics Covered
- **Core Language & Types:** Value vs. Reference types, `Span<T>`, `Tuples`, `Reflection`, `Pattern Matching`, `Nullable` types
- **Object-Oriented & Design Patterns:** Interfaces, Abstract classes, Generics, `Singleton` pattern, SOLID principles
- **Functional & Event-Driven:** `LINQ`, `Delegates`, `Events`, `Lambda` expressions
- **Concurrency & Low-Level:** `Async/Await`, `Tasks`, `Multithreading`, `Unsafe` code, `SizeOf`, `Pointers`
- **Error Handling & Diagnostics:** `Try/Catch/Finally`, custom exceptions

## How to Explore
1. Clone the repository:
   ```bash
   git clone https://github.com/glennpetero/CSharpFundamentals.git
   ```
2. Open `CSharpFundamentals.slnx` in Visual Studio or VS Code (with the C# Dev Kit extension) to inspect and run any of the 57 projects from a single solution.
